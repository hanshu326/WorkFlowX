# WorkFlowX

WorkFlowX is a Flask-based project and task management web application.

## Features

- User Registration and Login
- Role-based access
  - Admin
  - Manager
  - Employee
- Dashboard
- Project Management
- Task Management
- Task Assignment
- Task Status Updates
- Task Progress Tracking
- My Tasks
- Work Updates and Comments
- Notifications
- Mark as Read / Mark All as Read
- Search and Filter Tasks
- Overdue Task Detection
- Employee Management
- User Profile
- Analytics Dashboard
- Role-based Security
- Password Hashing
- CSRF Protection

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
